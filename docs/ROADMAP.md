# 分阶段实现路线

## Phase 0：基线

- 架构守卫、规则冲突文档、Agent 权限、CI。
- 纯领域引擎与规则测试。

## Phase 1：可玩闭环

- 创建/加入房间、准备、开局选将。
- 普通出牌、A 万化、四花色效果。
- 三大摸牌法则、阵亡换将、Joker 救援、游戏结束。
- 断线重连与脱敏同步。

## Phase 2：产品化

- 账户、排行榜、战绩、观战、房间设置。
- 音效、动效、移动端交互、无障碍。
- 运营后台与封禁/举报。

## Phase 3：扩展

- AI Bot、匹配队列、回放、压测。
- 多实例前先引入外部房间状态或一致性路由，禁止直接 PM2 cluster 造成房间分裂。
