# 验收清单

## 规则

- [ ] 2–12 人限制生效。
- [ ] 牌堆为 40 普通牌 + 2 Joker。
- [ ] 初始 5 张、上限 7 张。
- [ ] 多张同花色；含 A 时必须声明浸染花色；A 固定 +1。
- [ ] 同花色免疫；A 无视免疫。
- [ ] 黑桃双倍、红桃实际伤害吸血、方块轮序摸牌、梅花护盾/穿透。
- [ ] 空城补 3、换将摸 5、击杀者摸 3。
- [ ] 回合开始不自动摸牌。
- [ ] 濒死 10 秒、Joker 救援、超时淘汰。

## 网络

- [ ] 所有入站消息通过 Schema。
- [ ] 对手手牌脱敏。
- [ ] 15 秒心跳、3 秒退避、最多 5 次、30 秒重连窗口。
- [ ] 房主权限与非房主准备检查正确。
- [ ] 重复 requestId 不重复执行动作。

## UI

- [ ] 单一 boot 顺序；失败可见。
- [ ] 事件代理覆盖动态元素。
- [ ] 弹窗在 scene-layer 外。
- [ ] 暗色模式零 invert。
- [ ] 360px 无页面横向溢出。

## 运维

- [ ] `pnpm verify` 全绿。
- [ ] `/health`、WSS、Nginx、PM2 验证通过。
- [ ] 日志不含令牌、手牌或密钥。
- [ ] 回滚流程演练。
