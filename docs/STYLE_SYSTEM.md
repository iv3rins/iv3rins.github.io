# PokeWar 视觉样式规范 V2

## 1. 视觉语言

新粗野主义 + 酸性图形 + Bento Grid。关键词：高对比、纯黑粗线、无模糊硬阴影、重型标题、清晰正文。

## 2. Token

- 背景：`--color-bg: #F4F4F0`，禁止纯白作为页面底色。
- 主文字：`--color-text: #000000`。
- 酸性绿：`--color-primary: #CCFF00`。
- 电光蓝：`--color-secondary: #0057FF`。
- 危险红：`--color-danger: #FF3B30`。
- 花色红：`--color-suit-red: #DC2626`。
- 黑边：统一 `3px solid #000`。
- 默认硬阴影：`6px 6px 0 #000`；交互小阴影：`4px 4px 0 #000`。
- 间距：8px 基线；常用 8 / 12 / 16 / 24 / 32。

## 3. 排版

- Hero、伤害数字：Impact / Arial Black，允许描边与硬文字阴影。
- 卡片标题：重型字体，最多 1.5px 描边。
- 正文：Inter / system-ui，600 字重，1.6 行高；禁止描边、阴影、负字距。
- 最小正文 16px，交互标签不得低于 14px。

## 4. 组件

- Bento 卡片：12px 圆角、24px 内边距、3px 黑边、6px 硬阴影。
- 按钮：8px 圆角、12px 24px、4px 硬阴影；按下时位移并取消阴影。
- 输入框：6px 圆角、12px 内边距、明确焦点环。
- 弹窗：放在 `#scene-layer` 外的 `#overlay-layer`，避免页面切换隐藏。
- 关闭按钮：32×32 正圆，红底白叉，突破弹窗右上角。
- 选中手牌：上移 12px，`z-index: 200`，不能被相邻牌遮挡。

## 5. 暗色模式

只覆盖 CSS 变量。禁止 `filter: invert()`。图片、头像、Emoji 不做二次反转。

## 6. 动效

- 常规状态变化 120–200ms。
- 只动画 `transform` 与 `opacity`；避免布局抖动。
- 尊重 `prefers-reduced-motion`。
- 伤害、救援、Joker 可使用短促冲击动效，但不得阻塞输入。

## 7. 响应式

- 以 360px 手机宽度为最低基准。
- 桌面战场使用两列 Grid；小于 900px 切换单列。
- 手牌允许横向滚动，禁止整体页面横向溢出。
- 所有关键动作在拇指区可达，最小点击区域 44×44。
